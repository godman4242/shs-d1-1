# L0 — rewrite drafts

Each slice of the `REBUILD_READINESS.md` rewrite lands here twice, written by the agent
itself **before** it returns (wall insurance — see `../SALVAGE.md`):

- `<slice>.<tag>.md` / `.json` — the writer's draft and its exact structured return
- `<slice>.verify.<tag>.md` / `.json` — the blind verifier's attack on that draft

⛔ **The verifier never reads the writer's prose** (`GAUNTLET.md` §3.2). It sees the
submitted markdown and the artifacts, and nothing else — judging an argument instead of
evidence is how a wrong claim survives.

These are drafts and reviews, not the ledger. The finished document is assembled by the
lead from the approved slices, and gate **L0-B** re-checks every `[[claim]]` it ends up
citing against the pooled verdicts.
