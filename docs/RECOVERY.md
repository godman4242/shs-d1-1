## 4. Regenerating the 7,381 frames

⚠️ **The original ffmpeg invocation was never recorded** — there is no extraction script in
`scripts/` and no `ffmpeg` line in `docs/research/video-study/STUDY_PROTOCOL.md`. That is the
defect this section closes. What makes regeneration possible anyway is that **every filename
encodes its own timestamp**, so the frame set is self-describing.

Frames are **1920×1080**, one per named timestamp, across 20 purpose-named subdirectories.
Four naming conventions are in use — all carry the video id and the offset in seconds:

| Convention | Example | Offset |
|---|---|---|
| `<id>_t<sec>.png` | `Nr4fQstqHDM_t427.5.png` | 427.5 s |
| `<id>_<sec>.png` | `Nr4fQstqHDM_427.0.png` | 427.0 s |
| `<id>_<idx>.jpg` | `Nr4fQstqHDM_0005.jpg` | 5 s (survey pass, 1 fps) |
| `<id>_map_<idx>_t<sec>s.jpg` | `Nr4fQstqHDM_map_007_t296s.jpg` | 296 s |

To pull one frame at an exact offset (the general recipe — `-ss` before `-i` seeks fast, and
`-frames:v 1` takes exactly one):

```bash
ffmpeg -ss 427.5 -i reference/videos/Nr4fQstqHDM.mp4 -frames:v 1 -q:v 1 \
       reference/frames/combat_analysis/Nr4fQstqHDM_t427.5.png
```

To rebuild a whole directory from a surviving file list (the list is in git via the cites in
`docs/gauntlet/L0/`, and in `reference/frames/INDEX.json` if that survived):

```bash
while read -r p; do
  id=$(basename "$p" | cut -d_ -f1)
  t=$(basename "$p" | grep -oE '[0-9]+\.?[0-9]*' | tail -1)
  mkdir -p "$(dirname "$p")"
  ffmpeg -nostdin -loglevel error -ss "$t" -i "reference/videos/$id.mp4" \
         -frames:v 1 -q:v 1 "$p"
done < frame-list.txt
```

**VERIFY:** `find reference/frames -name '*.png' | wc -l` — was **4,217** PNGs of 7,381 total
files on 2026-08-24.

`reference/frames/INDEX.json` is **not** a recipe — it is a figure-bounding-box index keyed by
frame path. It is small and text; it is inside the seed archive.

## 5. The three custom crackers — original work, not Lut's

`reference/tools/` held three Python scripts, **written for this project**, that turn the shipped
SWF into the whole 504 MB payload. They were gitignored along with everything else under
`reference/`, which meant 295 lines of irreplaceable reverse-engineering had no copy anywhere:

| Script | Lines | What it implements |
|---|---:|---|
| `payload_decode.py` | 54 | the stage-3 preloader transform, read verbatim out of `shs3preloader_fla.MainTimeline` method `§1t136s0§`, key = 104 |
| `swfdefender_unwrap.py` | 138 | SWF Defender (magichtml.com) unwrapper; config layout read out of the decompiled `la` class |
| `tinyloader_crack.py` | 103 | the RC4 scheme from `shs3.swf`'s `lb` class — key is the blob's own last 8 bytes, only the first 64 bytes are encrypted |

They are **not** Lut Games assets and carry no distribution question, so a **byte-identical
tracked mirror** now lives in `scripts/payload/`, and they are inside the seed archive too.

⚠️ They were **copied, not moved**. L0's banked evidence cites the `reference/tools/` path
(`docs/research/fidelity/SOURCE_CONSTANTS.md:95-97`, `docs/gauntlet/L0/LEDGER_EVIDENCE.md`
and several critic files), and moving them would have invalidated banked cites. Edit both.
