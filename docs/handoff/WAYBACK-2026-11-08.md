## Re-verify recipe
1. `curl -sL 'http://web.archive.org/web/20161130113249im_/http://www.strawhatsamuraiduels.com/shs3_payload.swf' | shasum -a 256` → starts `b5009978ea9d4586…`
2. `python3 reference/tools/payload_decode.py reference/wayback-2026-11-08/shs3_payload_20161130_im.swf` → writes the decoded file, prints fileLength 11,892,652 and the inflate proof.
3. `python3 reference/wayback-2026-11-08/tag-audit.py` → prints "tags: A=4051 … / code/size mismatches: 1 / same-size content mismatches: 163".
4. Tag walk (inline, no deps):
```python
import struct, zlib
b = zlib.decompress(open("reference/decrypted/shs3_payload_20161130_im_decoded.swf","rb").read()[8:])
nb = b[0]>>3; p = (5+4*nb+7)//8 + 4
tags = []
while p+2 <= len(b):
    h = struct.unpack("<H", b[p:p+2])[0]; ln = h & 0x3F; hdr = 2
    if ln == 0x3F: ln = struct.unpack("<I", b[p+2:p+6])[0]; hdr = 6
    tags.append((h>>6, ln)); p += hdr + ln
print(len(tags))  # 4051
```
