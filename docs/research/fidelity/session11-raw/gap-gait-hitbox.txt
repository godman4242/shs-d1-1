### gap-gait-hitbox (16 rows)
SUMMARY: GAP E — SOLVED and then partly overturned. I found a WALK leg squarely inside the old 165–248 px @1080 blind spot: 197.2 px @1080 = 105.2 stage px (video A t=590.200–591.133), camera proved static by NCC signpost anchor and by a 0.51-mean whole-frame background diff, gait confirmed visually as upright short-step. On the run side the tightest clean point is 245.3 px = 130.8 stage px (A t=930.200–930.533), which independently reproduces last session's RUN@132. That narrows the plain-ground threshold from (88, 132] to (105.2, 130.8] stage px; a second RUN at 217.3 px = 115.9 stage px (A t=944.467–944.867) would tighten it to (105.2, 115.9], but it is only medium confidence because a "leaving territory" modal fires on the frame the run stops, so the leg may have been truncated. My pipeline also reproduced last session's WALK@63 (measured 63.4) as a sanity check. BUT the length-threshold model is falsified by two camera-verified, pose-verified counter-examples: a 379.1 px = 202.2 stage px WALK toward a lit map-exit hotspot (A t=1207.000–1208.800) and a 163.9 px = 87.4 stage px RUN toward a "BANDIT (4)" enemy (A t=1283.533–1283.733). Gait therefore looks like destination-type first (exit/transition ⇒ walk at any distance; hostile ⇒ run at any distance), with a distance threshold only for ordinary ground clicks. Also measured: WALK speed 211 px/s @1080 = 112.5 stage px/s (two legs agree to 0.4%), RUN top speed ≈825 px/s @1080 = 440 stage px/s with no acceleration ramp. GAP K — NOT BRACKETED, reported honestly as NOT-FOUND. I got one clean far-side MISS: an enemy sprite centre 75.5 px @1080 = 40.3 stage px beyond the far end of a stroke measured at x 877..1068 took no damage (A t=1407.733–1408.467, dungeon), which is only an upper bound and does not tighten last session's ~4 px result. The blocker is a real confound I did measure: damage resolves over the whole DASH SWEEP from the player's start position, not just the drawn line — two enemies BEHIND the line's near end died in that same slash — so only the far side of a line yields a usable hitbox reading. The bamboo window defeats bar segmentation (green foliage) and its stroke has a faint tail no single threshold isolates; the dungeon melee has 7 overlapping, pillar-split bars; the boss moves throughout the draw. Next session should use a single-enemy stationary duel and read hits from the red damage numerals rather than bar disappearance.
