### AGENT movement-gesture  (17 rows)
SUMMARY: Verdict: M2 (click-destination), leaning — medium confidence, M1 NOT strictly falsified. I could not settle it from developer text (the game never explains movement), so the verdict rests on behaviour. The decisive lever was discovering that the interaction tooltip renders AT THE MOUSE CURSOR (proved by the tooltip sliding 115 px horizontally and ~50 px vertically while the object it names and the camera stayed pixel-fixed) — that gives a direct cursor readout whenever an object is hovered. Three things then point to M2: (1) gait and speed are LATCHED for a whole leg and never track live cursor distance — in two arrivals with the cursor pinned, the character was still doing +54 to +55 px/tick (full run) when it was already inside the cursor's own tooltip span, where a live-cursor model with this game's demonstrable distance-based gait would have dropped to the 236 px/s walk; (2) the engine has NO acceleration (0 → +57 px in one 67 ms tick from a 2.6 s standstill), so any gradual speed change must be input-driven and none is; (3) the ONLY apparent M1 signature — a seamless walk→run mid-leg — turned out to be a SCRIPTED ZONE-ENTRY WALK: after every zone transition the character spawns at screen x≈232 and auto-walks to screen x≈397 (measured at 396.2 / 396.9 / 401.6 in three different zones) before player control resumes. Plus two interior stop→pause→resume-same-direction events (0.267 s and 0.800 s) and auto-firing of object interactions on arrival. Residual: no frame shows the character moving away from, or past, a lit tooltip, and a hold-to-move variant that latches its target on mouse-down would be indistinguishable here. Speeds (camera-scroll verified zero in every cited span, nameplate template-tracked): WALK 236 px/s @1080 = 126 stage px/s; RUN 639 px/s @1080 = 341 stage px/s; ratio 2.71. Our build's 280 stage px/s matches NEITHER — it is 2.22x the walk and 0.82x the run. Gait is picked by leg length (walk ≤165 px @1080, run ≥248 px; threshold unresolved in between). No click-marker FX exists anywhere (NOT-FOUND, checked at every arrival). Hard limit: the archival recording samples the game at only 15 Hz, so nothing faster than 67 ms is resolvable. 51 evidence frames + 8 analysis montages in /Users/kheshav/kheshav-code/SSHD 1-1/reference/frames/session11/movement-gesture/; dense bursts deleted.
