## Recreation notes   (config values to add/adjust, which build Stage this maps to, anything contradicting the repo's spec/research docs)
- Confirms a two-resource action-point economy: AP (action points, consumed by gathering: 2 AP for "Mine Coal Deposit," 1 AP for "Pick Silky Herb") is distinct from HP and Chi. Config should model AP as its own regen/cap stat, separate from Chi — Stats panel showed AP as high as 30/30, far larger scale than HP(20)/Chi(10).
- Weapon/tool items carry a DMG range with two sub-numbers formatted "DMG: min-max (EQ: min-max)" — e.g. Pickaxe "1-3 (EQ: 1-2)", Branch "1-2 (EQ: 1-3)". The "EQ" qualifier's exact meaning is unclear from visuals alone (possibly "equipped" bonus range vs base) — flag as INFERRED, needs cross-reference with a combat segment to confirm semantics before hardcoding into config.
- Tool durability/"CONDITION" field (e.g. "WELL-MAINTAINED") on mining tools, with an NPC-stated repurchase-from-peddler mechanic on breakage — relevant to Stage covering economy/equipment systems; a "peddler" merchant NPC type should exist in the recreation's NPC roster.
- Two currencies confirmed: "COINS" (main HUD, 122) and "GOLD" (Player-sheet only, 3) — recreation should keep these as separate ledger fields, not one currency mislabeled.
- Gathering-node UI pattern: quest-tracker box left of screen swaps between "! TALK TO X" (available dialogue), "STORY QUEST: <objective>" (active objective text), and "<pickaxe-icon> ACTION NAME — N AP" (interactable node prompt) — this is the HUD contract for all gather/quest interactions; recreation's quest-tracker widget should support these 3 sub-states.

- "REGISTER TO SAVE YOUR PROGRESS AND PLAY ONLINE!" banner is a live-ops/monetization nag from the original's web-portal version — explicitly NOT something to recreate (no account system planned per repo spec); noting only for completeness, not as a build target.
- No combat occurred in this segment; nothing here contradicts existing combat-related research docs. This segment is purely resource-gathering/quest-chain UX and should inform the recreation's "gathering minigame" or "interact node" system design once that Stage is reached.
