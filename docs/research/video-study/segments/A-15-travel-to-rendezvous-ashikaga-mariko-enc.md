## Feel               (pacing, camera, animation weight, FX; if combat: rough per-encounter durations in seconds)
- Overworld traversal is a slow, deliberate sidescroll walk-cycle; camera is a fixed side view per screen/room with location transitions cutting instantly between named zones (forest → field → sub-sectors), no visible scroll transition, just a hard cut with new location name-plate text.
- Environment art shifts palette by biome: castle town = warm cream/pink building tones under pale blue-green sky; SW Toshibara Forest = desaturated teal-grey dead trees, foggy/hazy background layering (parallax mist streaks); Toshibara Field = green grassy hills with tall grass silhouette foreground, soft cloud-streak sky FX identical style to forest (stylized wavy cloud/wind-streak overlay animating across the whole sky in both biomes).
- Combat is fast and arcade-y: enemies die in very few hits (bandit trio cleared in a 3-hit combo), blood-splatter particle FX on hit (small red particle burst + red slash-trail streaks), hit-combo counter kicks in immediately with a big red slashed-number graphic that escalates per consecutive hit.
- Victory transitions use a hard cut to a solid red silhouette "YOU WIN" splash screen (screenshake/flash style key art), then an immediate loot popup — very punchy, minimal downtime between fights and reward screens.
- NPC encounters (Yoko, Ashikaga Mariko) use the same lightweight dialogue-box UI as combat/quest prompts — consistent, reusable UI chrome throughout traversal, dialogue, and combat contexts.
- Duel felt narratively distinct from the random bandit mob (has a name-card VS intro splash, named/leveled single opponent) but mechanically resolved with the same instant win-screen pacing — this game does not appear to linger on individual duels; they are fast, almost cutscene-like beats.
